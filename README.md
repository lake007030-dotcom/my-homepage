# 我的几面

炭黑底、香槟金点缀的单页个人主页。背景是 **Canvas 实时渲染的光点场**，
首页是**五个等大的面**（关于我 / 人生记录 / 我在做 / 经历 / 联系我），点开任意一面看到具体的我。

纯 HTML / CSS / JS —— 零依赖、零构建，双击 `index.html` 就能看。
除「📍 定位我」时那一次城市名反查外，不请求任何外部资源。

**线上地址：** https://lake007030-dotcom.github.io/my-homepage/
**代码仓库：** https://github.com/lake007030-dotcom/my-homepage

## 先看这里：怎么改成你自己的

**编辑是「就地」的：哪一块内容，就在哪一块旁边改。** 没有统一的大表单。

| 你想改什么 | 点哪里 |
| --- | --- |
| 姓名 / 身份 / 一句话主张 / 标签 / 头像 | 首屏左上角那一块的右上角 → **✎ 改首屏** |
| 读数卡里的几行信息 | 读数卡标题右边的 **✎** |
| 我的几面（增删、改名、排序） | 「我的几面」标题右边的 **✎ 管理** |
| 三个数字 | 数字区右上角的 **✎ 改数字** |
| 邮箱 / 社交账号 | 联系条右上角的 **✎ 编辑联系** |
| 页脚版权、下载 profile.js、恢复默认 | 页脚右边的 **✎ 编辑页脚与备份** |
| **某一个面里的全部内容** | 进到那一面后，**右上角**的 **✎ 编辑这一面** |
| 坐标 | 读数卡里的 **📍 定位我** / **手填** |

每个 ✎ 点开就在原地摊开它的抽屉，改完点抽屉右上角的「**✓ 完成**」收起。
改动**自动保存**，不需要按保存键。键盘 `Esc` 也能收起，`Ctrl / ⌘ + E` 打开当前这块。

右下角常驻的 **✎ 编辑** 是个快捷菜单：它按你当前在哪个页面，列出这一页能改的几块，
点一下就跳到那块并展开。刚打开页面时右下角还会浮一条提示告诉你这件事。

### 换成你自己的照片（头像）

- **最省事**：鼠标移到首页右侧那个大头像上，会浮出「换照片」，点一下选本机图片。
- 也可以在「✎ 改首屏」抽屉里点「从电脑里选一张照片」。
- 图片自动压到最长边 900px 再存，不用管大小；点「用首字母」退回字母头像。

其它照片（相册里的）在 **进「人生记录」→ ✎ 编辑这一面 → 相册 → + 添加照片** 上传。

### 坐标：一键定位，或者自己填

读数卡里有一个**坐标**模块：

- **📍 定位我** → 浏览器弹出定位授权，允许后立刻显示 `31.2304° N · 121.4737° E`，
  并附带精度和「刚刚 / 3 分钟前」。
- **跟随** → 持续定位（`watchPosition`），你走动时坐标会一直更新；再点一次停止。
- **手填** → 自己敲城市、纬度和经度，显示格式一样。

想要城市名时，页面会额外请求一次公开的 OpenStreetMap 反查接口，把经纬度换成
「上海市 · 中国 · GMT+8」。这个请求**只在你点定位时才发生**；失败也不影响，
经纬度照样显示，城市名可以手填。页面本身依然零依赖、可离线打开。

> 浏览器定位有两个前提：**https 打开**（线上地址就行）和**你点过允许**。
> 本地双击 `file://` 打开时浏览器会禁止定位，页面会提示你手填。

> 提醒：这些改动只存在**这台浏览器**里。要让所有人都看到，点页脚的
> 「✎ 编辑页脚与备份 → 下载 profile.js」，用它覆盖同名文件后 `git push`（见第八节）。

## 二、页面结构

```
首页
├── 首屏（姓名 / 身份 / 一句话主张 / 标签 + 右侧读数卡：头像 · 坐标 · 信息行 · FPS）
├── 我的几面           ← 五个等大的卡片，点任意一个进入
│     关于我 · 人生记录 · 我在做 · 经历 · 联系我
├── 三个数字
└── 联系方式 + 社交平台

详情页（浏览器后退键可返回，顶部导航也能直接跳）
├── 右上角「✎ 编辑这一面」
└── 若干「内容块」，可任意混搭排序
```

五个面**完全平等、大小相同**，没有任何一个被特殊对待 —— 加面或删面之后依然如此。

### 点开一面时的「液态玻璃」转场

点任意一张卡片，你会看到：

1. 一块**磨砂玻璃**先正好盖住被点的那张卡片；
2. 玻璃像液体一样**漫开成整屏**，同时有一个金色**液滴从点击处涌出**并缓慢变形；
3. 一道**镜面高光**斜掠过玻璃表面；
4. 翻到详情页后玻璃**化开**，内容依次浮出。

进详情后背景还有三团**缓慢漂移的暖光**，鼠标划过卡片时玻璃上会有一片**跟着鼠标的高光**。
系统开了「减少动态效果」时会自动跳过这些动画，直接翻页（无障碍行为）。

### 8 种内容块

在 `profile.js` 的 `categories[].blocks` 里随便用、随便排：

```js
{ type: "text",     title: "小标题", body: "一段正文，可换行" }

{ type: "list",     title: "小标题", items: ["第一条", "第二条"] }

{ type: "tags",     title: "小标题", items: ["标签A", "标签B"] }

{ type: "stats",    title: "小标题", items: [{ n: "4", l: "交付的项目" }] }

{ type: "timeline", title: "小标题", items: [
    { time: "2023 — 现在", title: "独立开发", desc: "描述文字" } ] }

{ type: "links",    title: "小标题", items: [
    { name: "GitHub", url: "https://github.com/", note: "@yourname" } ] }

{ type: "photos",   title: "小标题", items: [            // 一整片照片网格
    { src: "assets/photos/海边.jpg", title: "标题", caption: "简介" } ] }

{ type: "albums",   title: "小标题", items: [            // 照片再分相册
    { name: "旅行 · 2024", desc: "相册说明",
      photos: [ { src: "assets/photos/海边.jpg", title: "标题", caption: "简介" } ] } ] }
```

`title` 都可以留空 `""`，那一块就不显示小标题。

## 四、加照片的两种方式

**A. 页面里上传**：见上，会自动压到宽 1600px 内嵌（方便，但 `profile.js` 会变大）。

**B. 放进文件夹（推荐，页面更轻）**：
把图片复制到 `assets/photos/`，在照片块里写 `src: "assets/photos/你的图片.jpg"`（路径用**正斜杠**）。

照片是 4:3 卡片，点击放大，所以**横构图**最好看。

## 五、社交平台

联系条右上角 **✎ 编辑联系**，或改 `profile.js` 的 `socials`：

```js
socials: [
  { name: "小红书", url: "https://xiaohongshu.com/user/profile/xxx",
    note: "@我的昵称", badge: "红", qr: "" },

  { name: "微信",   url: "",                       // 留空 = 不可点击
    note: "my-wechat-id", badge: "微", qr: "assets/photos/wechat-qr.png" }
]
```

| 字段 | 说明 |
| --- | --- |
| `name` | 平台名，随便写（知乎、即刻、B站、播客…） |
| `url` | 主页链接；留空则不可点击（适合微信号） |
| `note` | 账号或备注 |
| `badge` | 方框里的 1–2 个字，留空自动取平台名首字 |
| `qr` | 二维码图片路径，填了**鼠标移上去弹出二维码** |

徽标统一是炭黑底 + 金色描边，不再按平台生成彩色。

## 六、光点背景

`app.js` 里的光点场：三维空间随机分布 → 缓慢绕轴旋转 → 透视投影（越近越大越亮）→
邻近距离连线构成星座；鼠标附近有轻微斥力和一圈微光。三色：暖白 / 香槟金 / 暖灰。

想调整，改这段开头的数字：

```js
const COUNT = reduceMotion ? 0 : (small ? 52 : 112);  // 光点数量
const LINK_DIST = small ? 92 : 118;                   // 连线距离阈值
const MAX_LINKS = 190;                                // 每帧最多画多少条线
const COLORS = [[239,235,228],[201,169,106],[150,144,136]];  // 暖白 / 金 / 暖灰
```

- 电脑卡 → `112` 调到 `70`；手机想更丰富 → `52` 调大。
- 系统开了「减少动态效果」时会自动关动画、只画一帧静态图（无障碍行为）。
- 性能上用的是**预渲染贴图叠加**，不是每帧新建渐变。

首页右侧的 **FPS / 光点 / 分辨率** 是真实读数。

## 七、换配色与字体

`style.css` 最上面是全部可调项：

```css
:root{
  --gold: #C9A96A;      /* 香槟金：唯一强调色 */
  --bg:   #0A0A0B;      /* 炭黑底 */
  --ink:  #EFEBE4;      /* 暖白文字 */

  --glass: rgba(255,255,255,.038);        /* 玻璃底色 */
  --blur:  blur(16px) saturate(135%);     /* 玻璃模糊强度 */
  --ease-liquid: cubic-bezier(.16,1.02,.24,1);   /* 液态转场的缓动 */
}
```

### 字体（这一版换掉了「廉价感」的来源）

```css
--font-sans:    Inter → Noto Sans SC → 苹方 / 鸿蒙 / 微软雅黑   /* 正文 */
--font-display: Noto Serif SC → 思源宋体 → 宋体-简 → 华文中宋    /* 标题 */
--font-mono:    JetBrains Mono → Cascadia Mono → Consolas → 中文字体
```

两个关键点：

- **标题优先用 `Noto Serif SC`**（思源宋体的 Google 版，线条更干净）。你机器上已经装了它，
  所以线上和本地都是同一套字。故意**不放 `SimSun`**：宋体在大字号下笔画细、边缘发虚，就是「廉价感」的主要来源。
- **`--font-mono` 里必须带中文字体**。等宽字体（Consolas）没有汉字，浏览器会自己找替代，
  结果就是小标签里的中文掉进宋体 —— 这是最容易被忽略的一处。

想全部换成无衬线：把 `--font-display` 改成 `var(--font-sans)` 的值即可。

## 九、常见问题

**改了 `profile.js` 但页面没变？**
页面上的改动存在浏览器里，优先级更高。点页脚「✎ 编辑页脚与备份 → 恢复默认」清掉缓存即可。
（改数据结构时我会递增内部版本号，旧草稿会自动失效。）

**找不到编辑入口？** 记住一句话：**每块内容自己的右上角都有一个小 ✎**。
首屏、读数卡、我的几面、三个数字、联系条、页脚各有一个；进了某个面，右上角是「✎ 编辑这一面」；
右下角那个常驻的「✎ 编辑」是个快捷菜单，列出了当前页面能改的所有块。
手机上这些按钮一直都在。

**头像上传后换台电脑就没了？** 对 —— 页面里的改动只存在本机浏览器。
要让所有人看到，点「下载 profile.js」覆盖文件后 `git push`。

**照片点不开 / 显示不出来？**
路径要用正斜杠、区分大小写，并且文件名里尽量别用空格。

**微信链接点不动？** 微信没有个人网页，`url` 留空、改用 `qr` 二维码。

**手机上好看吗？** 响应式的：导航收起、卡片单列、光点数量自动降到 52，玻璃模糊强度也会降一档省电。

**转场动画卡顿？** 系统设置里开启「减少动态效果」即可自动降级；
或者把 `style.css` 里 `--blur` 从 `blur(16px)` 降到 `blur(10px)`，并减少 `app.js` 里的光点数量。

**定位没有反应？** 两种常见原因：① 用 `file://` 双击打开的（浏览器只在 https 下给定位权限），
请用线上地址；② 之前点过「拒绝」——在地址栏左侧的图标里重新允许，或直接用「手填」。
