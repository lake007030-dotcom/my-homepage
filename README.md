# 我的几面

**一块搁在白纸上的液态玻璃，背后是一条跟着鼠标走的细线。**
浅白底 + 缓慢流动的光雾 + 磨砂玻璃面板；鼠标划过去，会留下一条 1.8px 的冷灰细线，
松手后从尾到头慢慢淡掉。首页是**五个等大的面**（关于我 / 人生记录 / 我在做 / 经历 / 联系我），
点开任意一面看到具体的我；下面还有一片**相册/摄影**，用来长期放照片。

纯 HTML / CSS / JS —— 零依赖、零构建，双击 `index.html` 就能看，也能离线打开。
不请求任何外部资源（字体用本机已装的，没有网络也能正常显示）。

**线上地址：** https://lake007030-dotcom.github.io/my-homepage/
**代码仓库：** https://github.com/lake007030-dotcom/my-homepage

## 一、文件结构

| 文件 | 作用 | 要不要动 |
| --- | --- | --- |
| `index.html` | 页面骨架 | ❌ 不用动 |
| `style.css` | 全部样式（颜色、字体、节奏都在开头 `:root`） | 🔸 想调视觉才动 |
| `app.js` | 路由 + 内容渲染 + 玻璃交互 | ❌ 不用动 |

| **`profile.js`** | **你的全部内容**（个人资料 + 相册清单 `gallery`） | ✅ **只改这个** |
| `assets/photos/` | 放你的照片 | ✅ 往里丢图片 |

> 这一版**没有页内编辑器**：页面是给访客看的，编辑直接在 `profile.js` 里改。
> 好处是访客看到的永远是干净页面，而且代码从 2000 行掉到 500 行，加载更快。

### 动效是什么

- **纤细线条拖尾（主角）**：`glow.js` 用两张 canvas 画同一条轨迹 ——
  `#glowTop` 是**锐利层**（固定视口、`z-index: 35`），在正文卡片**之上**，所以线压在玻璃卡上
  也不会被卡片那层 `backdrop-filter: blur(30px)` 糊掉；因为 35 在顶栏 `.hud`（40）**之下**，
  线是从导航**底下**穿过去的 —— 导航文字永远压在线上方，不会横穿文字。`#glow` 是 `.bg` 里的**柔光层**
  （`CFG.bloom`，默认 `0.30`），被磨砂糊开，在卡片上留下一层朦胧光感。两张都
  `pointer-events: none`，点击 / 选中 / 悬停完全不受影响。
  - **线头永远就在鼠标上**：`glow.js` 记的是鼠标**真实走过的轨迹** —— 每个
    `pointermove` 里再用 `getCoalescedEvents()` 把浏览器合并掉的高频采样（一次事件
    常含 2~8 个点）也取出来，点的密度跟着鼠标速度走。（曾让线头按半衰期「追」鼠标，
    线头落后时补点补出的是**直线**，屏幕上就出现一条从另一头拉过来的**橡皮筋** —— 已彻底删掉。）
  - **跳变就断笔**：一次移动跨过 `CFG.jumpPx`（默认 `180` px）、或隔了
    `CFG.holdMs`（默认 `220` ms）又位移明显、或鼠标移出窗口再回来 —— 一律**另起一段**，
    两段之间不连线。所以「从屏幕一头拉一条直线到鼠标」在物理上不可能发生。
  - **路径是连续曲线，不是折线**：采样点之间用**带夹取的 Catmull-Rom** 转三次贝塞尔
    （控制点被压在两点之间、切线过长就缩到 1/3 以内），再按 `CFG.step`（默认 `2.5`px）
    **重新加密成一条曲线**才描边。所以不存在「一段一段直线拼出来」的接缝；
    夹取那个动作专门防住起笔/急转弯时曲线冲出去绕个小钩。
    **实测：密排螺旋最大转角 `0.8°`、来回折线 `0.05°`**（8px 直段那种做法是几十度）。
  - **颜色沿路径渐变**：整条线用一个线性渐变，每个点按自己的生命值取色标 ——
    头亮尾淡连续过渡，不是一节一节变色带。
  - **点一下** → 在指针位置补两个点，形成一小截短线。
  - **滚动页面时** → 立刻收笔：把所有点的剩余寿命压到 150ms 以内，
    沿着原来的淡出曲线在 0.15 秒里化掉。这一层是固定的，不这么做的话，
    那条线会「钉」在屏幕上、而内容在它底下滑走，看起来像一道浮在页面上的划痕。
  - **停手之后** → 每个点的生命值按**真实时间**衰减（`CFG.fadeMs` 默认 `520` ms、
    点寿命 `CFG.lifeMs` 默认 `950` ms），停手约 **0.8 秒**整条线就淡干净；
    点清零后立刻 `clearRect` 并**停掉 rAF** —— 待机时一帧都不画，不耗电。
  - **颜色（低饱和冷灰）**：默认 `rgba(145, 160, 175, 0.40)`。
    实测线条实际色 ≈ `rgb(138, 153, 169)`（蓝比红高 31），既不是纯灰也不是彩色。
  - **粗细与柔边**：本体 `lineWidth` 1.8px，另用一条同色宽线（`glowRatio` 1.9 倍、
    透明度 `glowAlpha` 0.30）打底柔化边缘；整条路径只画两遍，不是每段各画一次。
  - **时钟兜底**：内部用 `frameNow()` 统一时钟 —— 正常浏览器用 `performance.now()`，
    无头/虚拟时间下如果它一直停在 0，就按帧推进，保证淡出逻辑照常发生。
- **背景（底色）**：三层光雾（远 / 中 / 近）+ 两条液态柔光带 + 一层细网格。整页只有黑白灰。
  - **滚动时**：各层按**页面滚动进度**换算位移 —— 近层滚一屏走 60vh，远层几乎不动，
    液态带还会斜着漂并且反向旋转，所以越滚越能看出纵深。
  - **不滚动时**：雾团自身有 15～52 秒的缓慢漂移（越近越快）。
- **玻璃卡片**：一层磨砂模糊 + 一圈折射亮边 + 三层投影；
  卡片背后必须有东西可模糊（网格线、光雾的浓淡）—— 网格在卡片外清晰、进卡片就化开，
  这是最容易看出「玻璃」的一处。
  鼠标划过时另有一片跟着指针走的镜面反射，停在卡片上不动时也有一道常驻的左上窗光。
- **翻页**：视图淡入并轻微上浮。
- 系统开了「减少动态效果」时：入场动画、扫光、雾团的漂移全部关掉；
  **鼠标划过的线条保留**（更短、更淡）—— 那是用户自己触发的反应，
  关掉反而会让人觉得页面坏了。底色光雾与视差也保留，只把幅度压到三分之一。

> 一条经验：**「位移」不等于「看见在动」。**
> 又大又软的径向渐变移动几百像素，同一块像素可能只变化零点几个灰阶，肉眼完全无感。
> 所以雾团不能太大（≤ 44vh）、浓淡的落差不能铺满整个半径 —— 那才是「看得见的流动」。
>
> 第二条：**淡出要按「真实时间」算，不能按「帧」。**
> 每个点的生命值用 dt 指数衰减，低帧率机器上和高帧率机器上尾巴一样长；
> 一旦写成「每帧乘一次」，慢机器上这条线会拖得特别长、特别黏。
>
> 第三条：**点会先「透明」再被移除，所以别只看点数。**
> 光点淡到 0.004 以下才被 splice 掉，在那之前它虽然还在数组里，但画出来已经看不见。
> 判断「真的停了没有」要看 `running`（停手后必须回到 `false`）——
> 待机时点清零 → `clearRect` → 取消 rAF，一帧都不再画。
>
> 验收别只靠眼睛：`window.__glow.stats()` 给出帧数 / 总绘制数 / 时钟 / 点数 / 线头透明度 /
> 循环是否在跑；鼠标越过时还可以用 `getImageData` 直接量：
> 把「线条像素数 ÷ 有线像素列数」当平均线宽（实测 3~4px，含抗锯齿与渐隐尾段），
> 把线条像素的平均 RGB 拿来对色（实测 `rgb(138,153,169)`，确认它没跑成暖色）。

## 三、改内容（`profile.js`）

打开 `profile.js`，照着注释改。三个容易踩的坑：

1. 每行结尾的逗号不能少（最后一项可加可不加）。
2. 英文双引号要转义成 `\"`，或者改写成中文引号「」。
3. 图片路径用正斜杠：`assets/photos/a.jpg` ✅ `assets\photos\a.jpg` ❌

### 基本信息

```js
name:      "你的名字",
monogram:  "Y",                          // 没有头像照片时显示这个字
role:      "身份 / 头衔",
available: "开放合作 · 2025",              // 首屏那个小胶囊
statement: "以最少的元素，交付最确定的体验。",
accent:    "交付最确定的体验",              // 这句话底色会压一道浅灰记号笔；不想要就写 ""
avatar:    "assets/photos/avatar.svg",   // 留空 "" 就用上面的字
focus:     ["产品策略", "交互设计"],       // 标签，显示在名字下面
stats:     [ { n: "8 年", l: "产品与设计实践" } ],   // 首页的「三个数字」
```

### 8 种内容块

在 `categories[].blocks` 里随便用、随便排：

```js
{ type: "text",     title: "小标题", body: "一段正文，可换行" }

{ type: "list",     title: "小标题", items: ["第一条", "第二条"] }

{ type: "tags",     title: "小标题", items: ["标签A", "标签B"] }

{ type: "stats",    title: "小标题", items: [{ n: "4", l: "交付的项目" }] }

{ type: "timeline", title: "小标题", items: [
    { time: "2023 — 现在", title: "独立开发", desc: "描述文字" } ] }

{ type: "links",    title: "小标题", items: [
    { name: "GitHub", url: "https://github.com/", note: "@yourname" } ] }

{ type: "photos",   title: "小标题", items: [            // 一整片照片网格
    { src: "assets/photos/海边.jpg", title: "标题", caption: "简介" } ] }

{ type: "albums",   title: "小标题", items: [            // 照片再分相册
    { name: "旅行 · 2024", desc: "相册说明",
      photos: [ { src: "assets/photos/海边.jpg", title: "标题", caption: "简介" } ] } ] }
```

`title` 都可以留空 `""`，那一块就不显示小标题。
正文里用 `**两个字**` 可以加粗。

### 相册（点进「人生记录」）

- 顶部一排**相册胶囊**：`全部 7` `旅行 · 2024 2` `工作现场 2` …

```js
socials: [
  { name: "小红书", url: "https://xiaohongshu.com/user/profile/xxx",
    note: "@我的昵称", badge: "红", qr: "" },

  { name: "微信",   url: "",                       // 留空 = 不可点击
```

## 四、加照片：三个地方，一个套路

不管加到哪里，都是同一个套路：**先把图片拷进 `assets/photos/`，再改 `profile.js` 里对应的一行。**

**A. 首页「镜头里」（最省事，专门给你长期更新用）**
在 `profile.js` 最底下的 `gallery: [ ... ]` 里照抄一整行：

```js
{ src: "assets/photos/my-photo.jpg", title: "标题", caption: "一句话说明" },
```

存盘 → `Ctrl + F5`。想删就整行删掉，想换就只改 `src`，想调顺序就上下移动整行。
一张都不想放就把 `gallery` 写成 `[]`，首页那一块会自动消失（不会留空壳）。
**这就是「静态页面定期加照片」的最简办法：改一行、存盘、刷新，没有后台也没有编辑器。**

**B. 放进某个人生相册**（点进「人生记录」才有）
在对应相册的 `photos: [ ... ]` 里加一行，字段和上面完全一样。

**C. 用图床或 GitHub raw 链接**
把网址直接填进 `src` 也一样能用（但页面就不再是「离线也能看」了）。

照片是 4:3 卡片、点击放大，所以**横构图**最好看；
建议先把图压到 1600px 宽以内（一张 200–400 KB），页面才不会越用越慢。
路径区分大小写、必须用正斜杠，文件名里尽量别用中文和空格。

## 五、想微调视觉

颜色、字体、圆角、模糊强度全部集中在 `style.css` 开头的 `:root` 里：

```css
:root {
  --bg:        #F1F1EE;   /* 纸的底色 */
  --bg-top:    #FAFAF8;   /* 页面顶部，比底色再亮一点 */
  --bg-bottom: #EDEDEA;   /* 页面底部 */
  --ink:       #15171B;   /* 标题（近黑） */
  --body:      #4B5158;   /* 正文 */
  --ink-2:     #6E757E;   /* 次要 */
  --ink-3:     #8F959D;   /* 提示 */

  --cloud-lt:   255,255,255;   /* 光雾：白光 */
  --cloud-dk:   134,139,148;   /* 光雾：冷灰（只做极轻的暗调补充） */
  --cloud-warm: 176,166,150;   /* 光雾：暖灰 */

  --blur:      30px;      /* 玻璃模糊强度，手机上降到 15px */
  --sat:       165%;      /* 玻璃饱和度 */
  --maxw:      1160px;    /* 内容最大宽度 */
  --r:         22px;      /* 卡片圆角 */
}
```

**整页只有黑白灰，没有彩色** —— 这是刻意的，浅白纸面 + 无色玻璃最容易显高级。
现在唯一一处带色相的笔触是鼠标拖尾那条线（`glow.js` 的 `color: [145, 160, 175]`，
低饱和冷灰蓝）。它只在被划过时出现、两秒多就淡掉，远看仍然是一页灰白。
嫌它偏冷就把蓝色分量往红色那头挪（例如 `[160, 158, 152]`），
嫌它太明显就把 `lineAlpha` 从 `0.40` 收到 `0.28`。

**想调节明暗**：改 `.cloud.grey` / `.cloud.warm` 里的 `rgba(var(--cloud-dk), .26)`
那个小数（浓度）。数字越大画面越「有光有影」，越大越接近摄影棚的层次；
想更干净就往 `.18` 收。

**想改流动速度**：`.far / .mid / .near` 的 `--travel`（纵向走多少 vh）、`--dx`（横向走多少 vw），
以及 `.liquid.a / .liquid.b` 的 `--travel / --dx / --spin`（旋转多少度）。
数值越大移动越猛，0 就是不动。

**想整个换成深色底**：把 `--bg*` 改成深色、`--ink / --body` 改成浅色，
再把玻璃面板的 `rgba(255,255,255,…)` 和 `inset ... #fff` 一并反过来即可 —— 结构不用动。

### 线条拖尾（`glow.js` 开头那段 `CFG`）

| 想调什么 | 改哪个 | 怎么改 |
| --- | --- | --- |
| 拐弯**不够圆 / 看得出直段** | `step` | 曲线重新加密的点距，现在 `2.5` px。降到 `1.5` 几乎完美，`4` 以上会重新看出折角 |
| 轨迹**不够细腻** | `gap` | 每隔多少 px 记一个控制点，现在 `6`。越小越细（`4~5` 很棒），越大越省性能但拐弯会钝 |
| 快甩时**太野 / 尾巴太长** | `jumpPx` | 一次跨过多少 px 就断笔，现在 `180`。调小（`90~120`）会把快速甩动切成几段、更收得住；调大更容易连成一条长线 |
| 一顿一顿地动**还连着线** | `holdMs` | 隔多久再动就断笔，现在 `220` ms。觉得「停顿后又接上一段」就调到 `120` |
| 曲线**太圆 / 太直** | `tension` | 现在 `0.17`（允许 0.05~0.25）。调大更「甩」，调小更贴原轨迹 |
| 线**太显眼 / 太看不见** | `lineAlpha` | **深浅总开关**，现在 `0.40`（reduce `0.30`）。更隐形 `0.28`，更清楚 `0.5` |
| 线**太粗 / 太细** | `lineWidth` | 现在 `1.8` px，**建议只在 1.5 ~ 2.5 之间动**（再粗就成了光带，明确不要） |
| 边缘**太硬 / 太糊** | `glowRatio` `glowAlpha` | 打底柔边的相对宽度 `1.9` / 相对透明度 `0.30`。想要更雾就 `2.6 / 0.4`，想更利落就 `1.4 / 0.2` |
| 卡片上那层**朦胧光** | `bloom` | 底层柔光强度 `0.30`，设 `0` 就完全没有（锐利层还在，线照样看得见） |
| 尾巴**太长 / 太短** | `lifeMs` | 一个点从生到灭的总时长，现在 `950` ms。**这就是拖尾长度**，想短促就 `600` |
| 停手后**半天不消失** | `idleMs` `fadeMs` | 停手 `260` ms 后开始整条淡出、淡出用 `440` ms。**消失快慢 = 两者相加**；想更利落就 `150 / 280` |
| 颜色**偏冷 / 偏暖** | `color` | `[145, 160, 175]` 冷灰蓝。更冷 → `[120, 145, 170]`；几乎纯灰 → `[150, 155, 162]` |
| 极速甩动时**尾巴无限长** | `maxPts` | 现在 `26`，控制点数量上限 |

> 改 `glow.js` 只要记住四件事：**跟手看 `gap` / `jumpPx`，圆滑看 `step` / `tension`，
> 深浅粗细看 `lineAlpha` / `lineWidth`，长短与消失看 `lifeMs` / `idleMs` + `fadeMs`。**
> 改完读一次 `window.__glow.stats()`：`runs` 分了几段、`chord` 是段内最长点距
> （正常远小于 `jumpPx`）、`maxTurn` 是最大转角（正常低于 `1°`）；
> 停手约两秒后 `running` 变回 `false`，就说明循环确实停了（那时画布也已清空）。

改完记得 `Ctrl + F5` 强刷。

### 液态玻璃（`style.css` 里 `.glass` 那一段）

卡片是一整块「厚玻璃」，一共四层：

| 层 | 写在哪 | 是什么 |
| --- | --- | --- |
| 折射 | `.glass` 的 `backdrop-filter` | 先用 `index.html` 里那段 inline SVG 的 `#lgLens`（位移贴图）把背后的网格 / 光雾**揉一下**，再 `blur`。浏览器不支持 `url()` 时整条声明会被丢掉、自动退回纯 `blur`，**不会坏** |
| 玻璃厚度 | `.glass` 的 `box-shadow` 里那几条 `inset` | 上缘受光、下缘压暗、内部一圈回光（液体那点「鼓」） |
| 折射亮边 | `.glass::after` | 一圈 2px 渐变描边（左上最亮、右下压暗），并且极慢地自己流动（`lgDrift`，16s）—— 会流动才像液体，不动就只是塑料 |
| 镜面高光 | `.glass::before` | 跟着指针的亮点 + 柔光；悬停时再掠过一道高光（`sheenRun`） |

**立体（跟着指针微微倾斜）**：`app.js` 里的 `TILT = 5` 是最大倾角（度）。
指针在卡片左上角时卡片就向左上翻，离开归零。想更含蓄改 `2.5`，想更明显改 `8`（`10` 以上会晕）。
抬起高度走 `--lift`（`.facet:hover` 给 `-6px`，照片卡 `-5px`，链接卡 `-2px`）。

> 倾斜用的是 `transform`，所以**入场动画改用了独立的 `translate` 属性**（`.reveal` 那段）——
> 两者是分开的属性、可以叠加；千万别把它们写成同一个属性，否则会互相顶掉
> （这正是当初卡片怎么都不动的原因）。
> 另外照片卡 / 链接卡的折射材质写在 `style.css` **文件最末尾**：它们各自的规则里
> 已经有一条 `backdrop-filter`，同权重下只有后写的才盖得住。

### 字体

```css
--font-sans:    Inter → Noto Sans SC → 苹方 / 鸿蒙 / 微软雅黑   /* 正文 */
--font-display: Noto Serif SC → 思源宋体 → 宋体-简 → 华文中宋    /* 大标题 */
--font-mono:    JetBrains Mono → Cascadia Mono → Consolas → 中文字体
```

两个关键点：

- **大标题优先用 `Noto Serif SC`**（思源宋体的 Google 版，线条更干净）。
  故意**不放 `SimSun`**：宋体在大字号下笔画细、边缘发虚，是「廉价感」的主要来源。
- **`--font-mono` 里必须带中文字体**。等宽字体（Consolas）没有汉字，浏览器会自己找替代，
  结果小标签里的中文会掉进宋体 —— 最容易被忽略的一处。

想全部换成无衬线：把 `--font-display` 改成跟 `--font-sans` 一样即可。

## 六、存档与发布（git）

这个项目已经是一个 git 仓库，并且发布在 GitHub Pages 上。

### 大白话：存档、撤档分别是什么

**存档（commit + push）＝ 给整个网站拍一张快照，然后把它推到线上。**
拍完这张快照，以后任何时候都能把网站**完整还原**到这一刻的样子；
线上网址也会自动跟着更新（大约 1 分钟）。

**撤档（回退）＝ 把网站退回之前某一张快照。**
万一新版哪里难看、哪里点坏了，一句话就能退回去，而且**不会丢东西** ——
旧快照一直都留着，随时能再回来。

### 怎么存档

```bash
git add -A
git commit -m "更新内容"
git push
```

推送后 GitHub Pages 会自动重新构建，1 分钟左右线上就更新了。

```bash
git clone https://github.com/lake007030-dotcom/my-homepage.git
```

## 七、常见问题

**改了 `profile.js` 但页面没变？**
按 `Ctrl + F5` 强制刷新（浏览器会缓存 `.js`）。页面本身不再存草稿，改文件就一定生效。

**照片点不开 / 显示不出来？**
路径要用正斜杠、区分大小写，文件名里尽量别用空格。

**微信链接点不动？** 微信没有个人网页，`url` 留空、改用 `qr` 二维码。

**手机上好看吗？** 响应式的：导航收起、卡片单列、光雾层数减少（关掉近层）、玻璃模糊降一档省电。
手机（触摸）不画那条拖尾线 —— 手指底下本来也看不见它。

**划过去没有线？**
先确认 `glow.js` 被正常加载（`index.html` 底部那行 `<script src="glow.js">`），
再打开浏览器控制台敲 `__glow.stats()` —— 会返回
`{frames, paints, clockMs, points, verts, runs, chord, alpha, maxTurn, running, reduce, twoLayer}`。
划一下鼠标，`points` 和 `alpha` 应该从 `0` 跳起来、`running` 变 `true`；
停手约两秒后回到 `0 / false`（这时渲染循环真的停了、画布也清空了）。
`verts` 是加密后的曲线顶点数（26 个控制点大约会变成 60~160 个顶点），
`maxTurn` 是相邻两段的最大转角（**正常低于 1°**，一大就说明曲线出折角了），
`runs` 是这条尾巴被分成几段、`chord` 是段内最长点距（**正常远小于 `jumpPx`**；
它一大就说明又要把两个远点连起来了）。
划的时候 `points` 完全不动，就是脚本没进来。

**线太明显或太看不见？** 调 `glow.js` 里 `CFG.lineAlpha`（默认 `0.40`）——
它是「这支笔有多深」的总开关，往 `0.28`、`0.5` 各试一次就能找到手感。

**线不够顺、拐弯有棱角？** 依次看三个数：`step`（越小越圆滑）、
`tension`（越大越圆）、`gap`（越小越细腻）。正常默认值下 `maxTurn` 低于 `1°`。

**偶尔出现一条横贯屏幕的直线？** 那是「两个隔很远的点被连起来」了 ——
把 `jumpPx` 调小（`180 → 120`）、`holdMs` 调小（`220 → 140`）就能更早断笔。

**滚动或划过去有点卡？**
把 `style.css` 里 `--blur` 从 `30px` 降到 `18px`；
或把 `glow.js` 里的 `maxPts` 从 `26` 降到 `16`、`lifeMs` 从 `950` 降到 `600`
（少画一点、尾巴短一点）；
或在 `@media (max-width: 760px)` 那段里把 `.mid` 也加进 `display: none`（再少一层光雾）。
顺带一提：拖尾**只在划动后的约一秒**才跑动画，停手后点清零、循环停掉、画布清空，
所以待机时它一点电都不耗。

**首页「镜头里」怎么一张照片都没有？**
那是故意的：相册默认收成一行标题 + 一个「展开 ▾」按钮，**一张图都不请求**
（卡片和 `<img>` 都要等第一次点开才创建，图片地址先放在 `data-src` 里）。
点「展开」才会铺开照片墙；再点「收起 ⌃」会把 `<img>` 一起删掉，回到零请求。
想让它**默认就摊开**：在 `app.js` 的 `renderGallery()` 里把折叠判断那行的
`if (!state.expand)` 改成 `if (false)` 即可（或者干脆删掉那三行）。

**我想加一个「第六面」？** 在 `profile.js` 的 `categories` 里复制一块改掉 `id` 和内容即可，
`glyph` 写 `"06"`，布局会自动排。
