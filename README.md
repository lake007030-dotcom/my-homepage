# 我的几面

**一块搁在白纸上的液态玻璃，底下是一方静水。**
浅白底 + 缓慢流动的光雾 + 磨砂玻璃面板；鼠标划过去，水面会泛起一圈圈涟漪，
然后自己慢慢平复。首页是**五个等大的面**（关于我 / 人生记录 / 我在做 / 经历 / 联系我），
点开任意一面看到具体的我。

纯 HTML / CSS / JS —— 零依赖、零构建，双击 `index.html` 就能看，也能离线打开。
不请求任何外部资源（字体用本机已装的，没有网络也能正常显示）。

**线上地址：** https://lake007030-dotcom.github.io/my-homepage/
**代码仓库：** https://github.com/lake007030-dotcom/my-homepage

### 动效是什么

- **水面（主角）**：`water.js` 在背景里跑一个二维波动方程，把它画成一片极淡的水光。
  - **鼠标划过去** → 沿着轨迹落下几滴水（约每 75px 一滴），每颗散成一圈小涟漪；
    划得越快，水花稍大一点，但整体克制 —— 不会连成一长串盖住半屏。
  - **点一下** → 落一颗稍重的水珠。
  - **停手之后** → 涟漪大约两三秒就散了，也不会跑太远（一圈扩到三四百 px 就自己散完）；
    剩下的只是水底光斑在极慢地游（那是「水没死」的来源，不会停）。
  - **环境波**：每 5～11 秒在随机位置落一滴很轻的水（幅度约划过时的 7%），
    远看只是光在游 —— 这一层专治「长时间没人碰、看着像一张静止贴图」。
  - **框在水面之上** —— 见下面单独一段。
  - 网格线在水面**之下**，涟漪的明暗从它上面淌过去，看着像「水底的纹理」。
- **「各种框在水波的上方」是怎么做的**：
  玻璃卡片带 `backdrop-filter`，它会把**背后的水一起磨砂** ——
  于是「水从框下面流过」看起来就成了「波纹画在框上」。
  所以不是去调玻璃的厚薄（波纹总会从半透的白底下渗出来一点），
  而是**水面在框的位置干脆不画**：每一帧把落在框矩形里的格子 alpha 抹 0。
  框里于是只剩光雾和网格 —— 玻璃依旧是玻璃，但波纹永远不会出现在框上，
  卡片也永远纹丝不动。框的位置随滚动 / 换页重新采集（滚动时每帧最多收一次），
  换到详情页也会自动跟上。代价只有一点点：两张卡片之间那道二十来 px 的窄缝
  会因为没有水而看不出来，那本来也在两张卡的投影里，肉眼无感。
- **省电档**：指针停手 2 秒后，**渲染**降到 30fps（隔帧画一次）。
  注意降的是「画」，**仿真和时钟仍然按真实时间全速走** ——
  这两件事一旦被一起省掉，待机时水面速度和涟漪扩散都会只剩一半，看着就像静止的。
- **背景（水底）**：三层光雾（远 / 中 / 近）+ 两条液态柔光带 + 一层细网格。整页只有黑白灰。
  - **滚动时**：各层按**页面滚动进度**换算位移 —— 近层滚一屏走 60vh，远层几乎不动，
    液态带还会斜着漂并且反向旋转，所以越滚越能看出纵深。
  - **不滚动时**：雾团自身有 15～52 秒的缓慢漂移（越近越快）。
- **玻璃卡片**：一层磨砂模糊 + 一圈折射亮边 + 三层投影；
  卡片背后必须有东西可模糊（网格线、光雾的浓淡）—— 网格在卡片外清晰、进卡片就化开，
  这是最容易看出「玻璃」的一处。
  鼠标划过时另有一片跟着指针走的镜面反射，停在卡片上不动时也有一道常驻的左上窗光。
- **翻页**：视图淡入并轻微上浮。
- 系统开了「减少动态效果」时：入场动画、欢迎涟漪、环境波全部关掉；
  **鼠标涟漪保留**（幅度减半、干得更快，水更快回到平静）—— 那是用户自己触发的反应，
  关掉反而会让人觉得页面坏了。水底光雾的漂移也保留，只把幅度压到三分之一、周期拉长。

> 一条经验：**「位移」不等于「看见在动」。**
> 又大又软的径向渐变移动几百像素，同一块像素可能只变化零点几个灰阶，肉眼完全无感。
> 所以雾团不能太大（≤ 44vh）、浓淡的落差不能铺满整个半径 —— 那才是「看得见的流动」。
>
> 第二条：**衰减要按「真实时间」算，不能按「帧」。**
> 一开始水面十几秒都静不下来，就是因为全局阻尼写成了「每帧乘一次」，
> 而低帧率环境下几秒钟只跑了几十帧。现在按 dt 补步，帧率高低都一样。
>
> 第三条（踩得最冤的一条）：**省电档只能省「画」，不能连时间一起省。**
> 隔帧渲染那段代码如果把 `step()` 和时钟累加也一起 `return` 掉，
> 待机时仿真和漂移就只有一半速度 —— 在低帧率 / 省电模式的环境里，
> 水面会慢到看着像一张静止贴图，而你在高帧率机器上完全测不出来。
> 判断方法很直接：读 `window.__water.stats()`，看 `paints / frames` 是不是 0.5，
> 再看 `clockMs` 的增长是不是跟真实等待时间一致。
>
> 验收别只靠眼睛：`window.__water.stats()` 给出帧数 / 绘制数 / 每帧毫秒 / 时钟，
> 截图用逐像素比对（超过 4 个灰阶的像素占比）量化「水面到底动了没有」。
> 正常模式静置 5 秒约 14%，减弱动态效果模式约 3～7%（越低说明越接近静止贴图）。

1. 每行结尾的逗号不能少（最后一项可加可不加）。
2. 英文双引号要转义成 `\"`，或者改写成中文引号「」。

## 五、想微调视觉

颜色、字体、圆角、模糊强度全部集中在 `style.css` 开头的 `:root` 里：

```css
:root {
  --bg:        #F1F1EE;   /* 纸的底色 */
  --bg-top:    #FAFAF8;   /* 页面顶部，比底色再亮一点 */
  --bg-bottom: #EDEDEA;   /* 页面底部 */
  --ink:       #15171B;   /* 标题（近黑） */
  --body:      #4B5158;   /* 正文 */
  --ink-2:     #6E757E;   /* 次要 */
  --ink-3:     #8F959D;   /* 提示 */

  --cloud-lt:   255,255,255;   /* 光雾：白光 */
  --cloud-dk:   134,139,148;   /* 光雾：冷灰（只做极轻的暗调补充） */
  --cloud-warm: 176,166,150;   /* 光雾：暖灰 */

  --blur:      30px;      /* 玻璃模糊强度，手机上降到 15px */
  --sat:       165%;      /* 玻璃饱和度 */
  --maxw:      1160px;    /* 内容最大宽度 */
  --r:         22px;      /* 卡片圆角 */
}
```

**整页只有黑白灰，没有彩色** —— 这是刻意的，浅白纸面 + 无色玻璃最容易显高级。
唯一带一丝「水色」的地方是水面涟漪的波谷（`water.js` 里的 `cold: [150, 165, 181]`），
那是极淡的冷灰，用来让涟漪在浅白底上看得见；嫌它偏蓝就改成三档相等的灰（如 `150,150,150`）。

**想调节明暗**：改 `.cloud.grey` / `.cloud.warm` 里的 `rgba(var(--cloud-dk), .26)`
那个小数（浓度）。数字越大画面越「有光有影」，越大越接近摄影棚的层次；
想更干净就往 `.18` 收。

**想改流动速度**：`.far / .mid / .near` 的 `--travel`（纵向走多少 vh）、`--dx`（横向走多少 vw），
以及 `.liquid.a / .liquid.b` 的 `--travel / --dx / --spin`（旋转多少度）。
数值越大移动越猛，0 就是不动。

**想整个换成深色底**：把 `--bg*` 改成深色、`--ink / --body` 改成浅色，
再把玻璃面板的 `rgba(255,255,255,…)` 和 `inset ... #fff` 一并反过来即可 —— 结构不用动。

### 水面（`water.js` 开头那段 `CFG`）

| 想调什么 | 改哪个 | 怎么改 |
| --- | --- | --- |
| 涟漪**太淡 / 太抢** | `gain` | 坡度→法线倾角的放大倍数，现在 `7.5`。**最直接的一个旋钮**，±30% 就有明显区别 |
| 起伏**太平 / 太硬** | `wDiff` `wSpec` | 漫反射权重（明暗底子 `0.72`）与粼光权重（波峰那圈亮边 `0.30`）。`wSpec` 调大会更「锐」 |
| 太亮 / 太暗 | `hiA` `loA` | 迎光面最多加多少白（`176`）／背光面最多加多少冷灰（`122`） |
| 水**偏蓝 / 偏灰** | `cold` | 波谷的颜色，现在 `[176,186,198]` 极淡冷灰。改成三档相等的灰就完全没有颜色 |
| 划过去**水花太大** | `ampMax` | 一颗水珠的幅度上限，现在 `2.4`（reduce 下 `1.5`） |
| 慢慢划也想**明显一点** | `ampMin` `ampK` | 基础幅度 `0.62`、按指针速度加权 `0.42`。两个都调大就明显 |
| 涟漪**更密 / 更疏** | `dropGap` | 每移动「几格」落一滴（1 格 = `cell` px），现在 `11.5`（≈75px）。**调小 = 更密** |
| 传播**更远 / 更近** | `damping` | 每小步乘一次的衰减，现在 `0.9775`（reduce `0.968`）。**调小 = 传得更近、干得更快** |
| 水面**更细腻** | `cell` | 一格多少 CSS px，现在 `6.5`。调小更细腻也更费电，建议不低于 `6` |
| 不要**欢迎涟漪 / 环境波** | `!reduce` 那行 | `breeze: !reduce` 改成 `false` 就没有自发的小水波了 |
| 环境波**太频繁** | `breezeMin` `breezeMax` | 两道自发水波之间的间隔（秒），现在 `5 / 11`。调大 = 更安静 |
| 水底光斑**动得快慢** | `tA` `tB` | 光斑漂移的 x / y 周期（秒），现在 `26 / 19`（reduce `40 / 29`）。**别调太快** |
| 哪些元素**要盖住水** | 代码里的 `PANEL_SEL` | 水面不在这些元素的位置绘制。**别把没有背景的元素加进去**（比如透明的容器），否则会凭空出现一块「没有水」的区域 |

> 改 `water.js` 有个前提：**先想清楚改的是「仿真」「光照」「挖洞」还是「省电」**，
> 这几块在同一个文件里但是互不干扰的。改完读一次 `window.__water.stats()`，
> 确认 `paints / frames` 还是 0.5、`clockMs` 跟真实时间对得上，就知道有没有碰坏。

改完记得 `Ctrl + F5` 强刷。

### 字体

```css
--font-sans:    Inter → Noto Sans SC → 苹方 / 鸿蒙 / 微软雅黑   /* 正文 */
--font-display: Noto Serif SC → 思源宋体 → 宋体-简 → 华文中宋    /* 大标题 */
--font-mono:    JetBrains Mono → Cascadia Mono → Consolas → 中文字体
```

两个关键点：

- **大标题优先用 `Noto Serif SC`**（思源宋体的 Google 版，线条更干净）。
  故意**不放 `SimSun`**：宋体在大字号下笔画细、边缘发虚，是「廉价感」的主要来源。
- **`--font-mono` 里必须带中文字体**。等宽字体（Consolas）没有汉字，浏览器会自己找替代，
  结果小标签里的中文会掉进宋体 —— 最容易被忽略的一处。

想全部换成无衬线：把 `--font-display` 改成跟 `--font-sans` 一样即可。

## 六、存档与发布（git）

这个项目已经是一个 git 仓库，并且发布在 GitHub Pages 上。

### 大白话：存档、撤档分别是什么

**存档（commit + push）＝ 给整个网站拍一张快照，然后把它推到线上。**
拍完这张快照，以后任何时候都能把网站**完整还原**到这一刻的样子；
线上网址也会自动跟着更新（大约 1 分钟）。

**撤档（回退）＝ 把网站退回之前某一张快照。**
万一新版哪里难看、哪里点坏了，一句话就能退回去，而且**不会丢东西** ——
旧快照一直都留着，随时能再回来。

### 怎么存档

```bash
git add -A
git commit -m "更新内容"
git push
```

推送后 GitHub Pages 会自动重新构建，1 分钟左右线上就更新了。

## 七、常见问题

**改了 `profile.js` 但页面没变？**
按 `Ctrl + F5` 强制刷新（浏览器会缓存 `.js`）。页面本身不再存草稿，改文件就一定生效。

**照片点不开 / 显示不出来？**
路径要用正斜杠、区分大小写，文件名里尽量别用空格。

**微信链接点不动？** 微信没有个人网页，`url` 留空、改用 `qr` 二维码。

**手机上好看吗？** 响应式的：导航收起、卡片单列、光雾层数减少（关掉近层）、玻璃模糊降一档省电。
手机上手指划过屏幕同样会起涟漪。

**划过去水没什么反应？**
先确认 `water.js` 被正常加载（`index.html` 底部那行 `<script src="water.js">`），
再打开浏览器控制台敲 `__water.stats()` —— 会返回 `{W, H, cell, energy, running, frames}`。
划一下鼠标，`energy` 应该从 `0` 跳起来、`running` 变 `true`；停手几秒后回到 `0 / false`。
要是数字完全不动，就是脚本没进来。

**水面太淡或太吵？** 调 `water.js` 开头的 `gain`，它是唯一的「总亮度」旋钮。
嫌它一直动、静不下来，把 `damping` 往 `0.96` 调，或者把 `ambient` 设成 `false`。

**滚动或划水有点卡？**
把 `style.css` 里 `--blur` 从 `30px` 降到 `18px`；
或把 `water.js` 里的 `cell` 从 `7` 调大到 `9`（水面分辨率更低、更省电）；
或在 `@media (max-width: 760px)` 那段里把 `.mid` 也加进 `display: none`（再少一层光雾）。
顺带一提：水面**只在被搅动的那几秒**才跑动画，平静时循环是停掉的，所以待机几乎不耗电。

**我想加一个「第六面」？** 在 `profile.js` 的 `categories` 里复制一块改掉 `id` 和内容即可，
`glyph` 写 `"06"`，布局会自动排。
