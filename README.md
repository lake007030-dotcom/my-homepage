# 我的几面

**黑 · 灰 · 白**三色（不带任何彩色）的单页个人主页，配色一键切换。
背景是 **Canvas 实时渲染的光点场**，
首页是**五个等大的面**（关于我 / 人生记录 / 我在做 / 经历 / 联系我），点开任意一面看到具体的我。

纯 HTML / CSS / JS —— 零依赖、零构建，双击 `index.html` 就能看。
除「📍 定位我」时那一次城市名反查外，不请求任何外部资源。

**线上地址：** https://lake007030-dotcom.github.io/my-homepage/
**代码仓库：** https://github.com/lake007030-dotcom/my-homepage

## 先看这里：怎么改成你自己的

**编辑是「就地」的：哪一块内容，就在哪一块旁边改。** 没有统一的大表单。

| 你想改什么 | 点哪里 |
| --- | --- |
| 姓名 / 身份 / 一句话主张 / 标签 / 头像 | 首屏左上角那一块的右上角 → **✎ 改首屏** |
| 读数卡里的几行信息 | 读数卡标题右边的 **✎** |
| 我的几面（增删、改名、排序） | 「我的几面」标题右边的 **✎ 管理** |
| 三个数字 | 数字区右上角的 **✎ 改数字** |
| 邮箱 / 社交账号 | 联系条右上角的 **✎ 编辑联系** |
| 页脚版权、下载 profile.js、恢复默认 | 页脚右边的 **✎ 编辑页脚与备份** |
| **某一个面里的全部内容** | 进到那一面后，**右上角**的 **✎ 编辑这一面** |
| 坐标 | 读数卡里的 **📍 定位我** / **跟随** / **手填** |
| **界面配色（黑 / 灰 / 白）** | 页脚右边的 **✎ 编辑页脚与备份** → 界面颜色 |

每个 ✎ 点开就在原地摊开它的抽屉，改完点抽屉右上角的「**✓ 完成**」收起。
改动**自动保存**，不需要按保存键。键盘 `Esc` 也能收起，`Ctrl / ⌘ + E` 打开当前这块。

右下角常驻的 **✎ 编辑** 是个快捷菜单：它按你当前在哪个页面，列出这一页能改的几块，
点一下就跳到那块并展开。刚打开页面时右下角还会浮一条提示告诉你这件事。

### 换成你自己的照片（头像）

- **最省事**：鼠标移到首页右侧那个大头像上，会浮出「换照片」，点一下选本机图片。
- 也可以在「✎ 改首屏」抽屉里点「从电脑里选一张照片」。
- 图片自动压到最长边 900px 再存，不用管大小；点「用首字母」退回字母头像。

其它照片（相册里的）在 **进「人生记录」→ ✎ 编辑这一面 → 相册 → + 添加照片** 上传。

### 坐标：点一下就该有，不用自己去翻浏览器设置

读数卡里有一个**坐标**模块，四条路任选：

| 按钮 | 会发生什么 | 要不要权限 |
| --- | --- | --- |
| **📍 定位我** | 先在页面上弹一张说明卡讲清楚要干什么，你点「允许并定位」后浏览器才问你要权限；允许后立刻显示 `31.2304° N · 121.4737° E`，带精度和「刚刚 / 3 分钟前」 | 要 |
| **跟随** | 持续定位（`watchPosition`），你走动时坐标一直更新；再点一次停止 | 要（同上） |
| **🌐 网络粗略定位** | 不用任何权限，按网络出口估个大概位置，只精确到城市（约 ±25 公里） | 不要 |
| **手填** | 自己敲城市、纬度和经度，显示格式完全一样 | 不要 |

**如果之前点过「阻止」**：浏览器就记住不再问了 —— 这是浏览器的安全规矩，
网页自己没办法再弹窗求你同意（不是偷懒）。这时页面会弹一张卡，按你的浏览器
（Chrome / Edge / Firefox / Safari 分别不同）给出**三步开启指引**，照着点一次就永久有效；
懒得弄就直接用「网络粗略定位」或「手填」，一样能出坐标。

想要城市名时，页面会额外请求一次公开的 OpenStreetMap 反查接口，把经纬度换成
「上海市 · 中国 · GMT+8」。这个请求**只在你点定位时才发生**；失败也不影响，
经纬度照样显示，城市名可以手填。页面本身依然零依赖、可离线打开。

> 浏览器定位有两个前提：**https 打开**（线上地址就行）和**你点过允许**。
> 本地双击 `file://` 打开时浏览器一律禁止定位，页面会直接告诉你，并给出网络定位和手填两条路。

> 提醒：这些改动只存在**这台浏览器**里。要让所有人都看到，点页脚的
> 「✎ 编辑页脚与备份 → 下载 profile.js」，用它覆盖同名文件后存档（见第八节）。

### 点开一面时的「液态玻璃」转场

点任意一张卡片，你会看到：

1. 一块**磨砂玻璃**先正好盖住被点的那张卡片；
2. 玻璃像液体一样**漫开成整屏**，同时有一个**液滴从点击处涌出**并缓慢变形；
3. 一道**镜面高光**斜掠过玻璃表面；
4. 翻到详情页后玻璃**化开**，内容依次浮出。

进详情后背景还有三团**缓慢漂移的光雾**，鼠标划过卡片时玻璃上会有一片**跟着鼠标的高光**。
系统开了「减少动态效果」时会自动跳过这些动画，直接翻页（无障碍行为）。

## 六、光点背景

`app.js` 里的光点场：三维空间随机分布 → 缓慢绕轴旋转 → 透视投影（越近越大越亮）→
邻近距离连线构成星座；鼠标附近有轻微斥力和一圈微光。
光点颜色**跟着配色主题走**（从 CSS 变量里读），换主题不用改 JS。

想调整，改这段开头的数字：

```js
const COUNT = reduceMotion ? 0 : (small ? 52 : 112);  // 光点数量
const LINK_DIST = small ? 92 : 118;                   // 连线距离阈值
const MAX_LINKS = 190;                                // 每帧最多画多少条线
// 光点颜色不用改这里：读的是 style.css 里的 --ink / --accent-rgb / --ink-3
```

- 电脑卡 → `112` 调到 `70`；手机想更丰富 → `52` 调大。
- 系统开了「减少动态效果」时会自动关动画、只画一帧静态图（无障碍行为）。
- 性能上用的是**预渲染贴图叠加**，不是每帧新建渐变。

首页右侧的 **FPS / 光点 / 分辨率** 是真实读数。

## 七、配色与字体

### 三套单色主题，随便挑

点页面右下角 **✎ 编辑 → 界面颜色 / 下载备份**（或页脚的 **✎ 编辑页脚与备份**），
里面有三个按钮，点一下**立刻生效**，并且会被记住（下次打开还是它）：

| 主题 | 底色 | 适合什么时候用 |
| --- | --- | --- |
| **曜石 · 纯黑** | `#000000` 纯黑 | 晚上，想要最沉的高级感（默认） |
| **石墨 · 深灰** | `#131313` 深灰 | 白天室内，长时间盯着更柔和 |
| **宣纸 · 浅白** | `#F1F1EF` 浅灰白 | 亮环境 / 白天，白底黑字最清楚 |

三套都只有**黑、灰、白**，没有任何彩色点缀 —— 强调色就是「更亮的白」。
颜色用 `--*-rgb`（三个数字）形式定义，好处是能在 `rgba()` 里直接配透明度：

```css
:root{                                  /* 曜石 · 纯黑（默认） */
  --bg:        #000000;                 /* 底色 */
  --panel-rgb: 12,12,12;                /* 浮层 / 弹窗的底 */
  --surf-rgb:  255,255,255;             /* 面板、描边、光晕 */
  --accent-rgb:255,255,255;             /* 强调色 = 白 */
  --ink:  #FAFAFA;  --ink-2:#B0B0B0;  --ink-3:#767676;   /* 正文 / 次要 / 提示 */

  --blur: blur(18px) saturate(112%);    /* 玻璃模糊强度 */
  --ease-liquid: cubic-bezier(.16,1.02,.24,1);   /* 液态转场的缓动 */
}
```

想再微调一档（比如觉得纯黑太死），改这一段里几个数就行；另外两套主题在文件**末尾**的
`[data-theme="graphite"]` / `[data-theme="paper"]` 里，照抄改数即可。

### 字体（这一版换掉了「廉价感」的来源）

```css
--font-sans:    Inter → Noto Sans SC → 苹方 / 鸿蒙 / 微软雅黑   /* 正文 */
--font-display: Noto Serif SC → 思源宋体 → 宋体-简 → 华文中宋    /* 标题 */
--font-mono:    JetBrains Mono → Cascadia Mono → Consolas → 中文字体
```

两个关键点：

- **标题优先用 `Noto Serif SC`**（思源宋体的 Google 版，线条更干净）。你机器上已经装了它，
  所以线上和本地都是同一套字。故意**不放 `SimSun`**：宋体在大字号下笔画细、边缘发虚，就是「廉价感」的主要来源。
- **`--font-mono` 里必须带中文字体**。等宽字体（Consolas）没有汉字，浏览器会自己找替代，
  结果就是小标签里的中文掉进宋体 —— 这是最容易被忽略的一处。

想全部换成无衬线：把 `--font-display` 改成 `var(--font-sans)` 的值即可。

## 八、存档与发布（git）

这个项目已经是一个 git 仓库，并且发布在 GitHub Pages 上。

### 大白话：存档、撤档分别是什么

**存档（commit + push）＝ 给整个网站拍一张快照，然后把它推到线上。**
拍完这张快照，以后任何时候都能把网站**完整还原**到这一刻的样子；
线上网址也会自动跟着更新（大约 1 分钟）。

**撤档（回退）＝ 把网站退回之前某一张快照。**
万一新版哪里难看、哪里点坏了，一句话就能退回去，而且**不会丢东西** ——
旧快照一直都留着，随时能再回来。

所以在这里，**你什么都不用记**：改完交给存档的人（或者我）就行 ——
什么时候存档、要不要撤档，由存档的人判断，做完会告诉你「存了哪一版、存了什么」。
你只需要做两件事：**看一眼效果**、**说哪里不舒服**。

### 改完内容后怎么存档（给想自己动手的人）

```bash
git add -A
git commit -m "更新内容"
git push
```

推送后 GitHub Pages 会自动重新构建，1 分钟左右线上就更新了。

### 换一台电脑继续改

```bash
git clone https://github.com/lake007030-dotcom/my-homepage.git
```

## 九、常见问题

**改了 `profile.js` 但页面没变？**
页面上的改动存在浏览器里，优先级更高。点页脚「✎ 编辑页脚与备份 → 恢复默认」清掉缓存即可。
（改数据结构时我会递增内部版本号，旧草稿会自动失效。）

**找不到编辑入口？** 记住一句话：**每块内容自己的右上角都有一个小 ✎**。
首屏、读数卡、我的几面、三个数字、联系条、页脚各有一个；进了某个面，右上角是「✎ 编辑这一面」；
右下角那个常驻的「✎ 编辑」是个快捷菜单，列出了当前页面能改的所有块。
手机上这些按钮一直都在。

**头像上传后换台电脑就没了？** 对 —— 页面里的改动只存在本机浏览器。
要让所有人看到，点「下载 profile.js」覆盖文件后 `git push`。

**照片点不开 / 显示不出来？**
路径要用正斜杠、区分大小写，并且文件名里尽量别用空格。

**微信链接点不动？** 微信没有个人网页，`url` 留空、改用 `qr` 二维码。

**手机上好看吗？** 响应式的：导航收起、卡片单列、光点数量自动降到 52，玻璃模糊强度也会降一档省电。

**转场动画卡顿？** 系统设置里开启「减少动态效果」即可自动降级；
或者把 `style.css` 里 `--blur` 从 `blur(16px)` 降到 `blur(10px)`，并减少 `app.js` 里的光点数量。

**定位没有反应？** 现在点「📍 定位我」会直接在页面中间弹一张卡，把原因和下一步都写清楚：

- 用 `file://` 双击打开的 → 浏览器一律不给定位权限，卡片会说明，并给出网络定位、手填两条路；
- 之前点过「阻止」→ 浏览器不会再问第二次，卡片会按你的浏览器给出**三步开启指引**；
- 不想动设置 → 点卡片里的「🌐 网络粗略定位」（不需要任何权限，精确到城市）或「手填坐标」。
